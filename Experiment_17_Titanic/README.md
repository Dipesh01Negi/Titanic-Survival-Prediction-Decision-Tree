# Titanic Survival Prediction using Decision Tree Classifier

A machine learning project that predicts whether a passenger survived the Titanic disaster using a Decision Tree Classifier implemented with Python and Scikit-learn.

## Project Overview

The objective of this project is to build a machine learning classification model that predicts passenger survival based on demographic and travel-related information.

The project follows a complete machine learning workflow:

- Loading and exploring the dataset
- Data preprocessing
- Handling missing values
- Removing unnecessary columns
- Encoding categorical variables
- Splitting the dataset into training and testing sets
- Training a Decision Tree Classifier
- Evaluating model performance
- Analyzing feature importance
- Generating visualizations

## Algorithm Used

### Decision Tree Classifier

Decision Tree Classifier is a supervised machine learning algorithm used for classification problems.

The model creates a tree-like structure of decision rules and uses these rules to classify data into different categories.

In this project, the model predicts whether a Titanic passenger survived or did not survive.

Target variable:

```text
0 = Did Not Survive
1 = Survived
